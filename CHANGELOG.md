# Changelog

## 1.0.2
- Première publication sur GitHub, compatible HACS.
- Lecture des données de Battery Sentinel Plus (seuils par appareil, type et nombre de piles, dernier remplacement, appareils injoignables, alertes en pause, appareils ignorés).
- Lignes colorées animées (apparition en cascade, jauge, alerte qui pulse), liste repliable, bouton d'actualisation.
- Un toucher sur une ligne ouvre la page de l'appareil.
- Repli automatique sur les batteries de Home Assistant si Sentinel n'est pas disponible.
- Éditeur visuel complet.
